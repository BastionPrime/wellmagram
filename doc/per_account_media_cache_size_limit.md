# PerAccountMediaCache - Размерный потолок кэша

## Описание проблемы
Изначальная реализация `PerAccountMediaCache` не имела ограничений по размеру, что создавало риск переполнения хранилища на Android устройствах. Кэш мог расти неограниченно до тех пор, пока аккаунт не будет удален.

## Решение
Добавлена новая реализация `PerAccountMediaCache` с:

1. **Ограничением размера** - каждый аккаунт имеет собственный лимит по умолчанию 50 МБ
2. **Политикой eviction (LRU)** - при превышении лимита удаляются наименее используемые файлы
3. **Конфигурацией лимита** - можно задать пользовательский лимит через параметр `maxSizeBytes`
4. **Отслеживанием размера** - в памяти отслеживается размер кэша для каждого аккаунта
5. **Обновляемым временем доступа** - метод `touch()` обновляет время последнего доступа к файлу для правильной работы LRU

## Архитектура изменений

### Новые методы:
- `trackFile(AccountKey, String)` - добавляет файл в отслеживание и запускает eviction при необходимости
- `touch(AccountKey, String)` - обновляет время последнего доступа к файлу
- `getCurrentSize(AccountKey)` - возвращает текущий размер кэша для аккаунта
- `calculateActualSize(AccountKey)` - вычисляет фактический размер директории (альтернатива отслеживанию в памяти)

### Параметры:
- `maxSizeBytes` - максимальный размер кэша в байтах (по умолчанию 50MB)

## Пример использования

```dart
// Создание кэша с лимитом 100MB
var cache = PerAccountMediaCache(
  paths: accountPaths,
  fs: accountFs,
  maxSizeBytes: 100 * 1024 * 1024  // 100MB
);

// Добавление файла в кэш (автоматически запускает eviction при необходимости)
await cache.trackFile(account, '/path/to/media/file.jpg');

// Обновление времени доступа к файлу (для LRU)
await cache.touch(account, '/path/to/media/file.jpg');

// Получение текущего размера кэша
int currentSize = await cache.getCurrentSize(account);
```

## Политика eviction (LRU)
1. При добавлении нового файла проверяется общий размер кэша
2. Если размер превышает лимит, запускается процесс очистки
3. Файлы сортируются по времени последнего доступа (старые - первыми)
4. Самые старые файлы удаляются до тех пор, пока общий размер не станет меньше лимита

- Интерфейсы остались без изменений
