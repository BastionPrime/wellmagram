# OPE-3894: PerAccountMediaCache — размерный потолок кэша

## Изменения

### 1. Обновленный PerAccountMediaCache
- Добавлена поддержка ограничения размера кэша (по умолчанию 50MB на аккаунт)
- Реализована политика eviction (LRU) для автоматического удаления старых файлов при превышении лимита
- Добавлено отслеживание размера кэша в памяти
- Добавлены методы для обновления времени доступа к файлам (для LRU)
- Добавлена возможность настройки лимита через конструктор

### 2. Новые методы
- `trackFile(account, filePath)` — добавляет файл в отслеживание и запускает eviction при необходимости
- `touch(account, filePath)` — обновляет время последнего доступа к файлу
- `getCurrentSize(account)` — возвращает текущий размер кэша для аккаунта
- `calculateActualSize(account)` — вычисляет фактический размер директории

### 3. Конфигурация
- Добавлен файл конфигурации `lib/config/cache_config.dart` с настройками лимитов
- Поддержка различных профилей устройств (low_end, mid_range, high_end, tablet)

### 4. Тесты
- Обновлены тесты для проверки новой функциональности
- Добавлены тесты для проверки политики eviction
- Проверена обратная совместимость

### 5. Документация
- Добавлена документация по новой функциональности
- Примеры использования в `example/per_account_media_cache_usage.dart`

## Политика eviction (LRU)
При добавлении новых файлов в кэш:
1. Проверяется общий размер кэша для аккаунта
2. Если размер превышает лимит, запускается процесс очистки
3. Файлы сортируются по времени последнего доступа (старые - первыми)
4. Самые старые файлы удаляются до тех пор, пока общий размер не станет меньше лимита

## Обратная совместимость
- Все существующие методы работают как раньше
- По умолчанию используется лимит 50MB, который можно изменить
- Интерфейсы остались без изменений

## Риски
- Время выполнения операций может увеличиться при больших кэшах из-за необходимости проверки размера и возможной очистки
- Необходимо убедиться, что приложение правильно обрабатывает ситуацию, когда файлы были удалены политикой eviction
